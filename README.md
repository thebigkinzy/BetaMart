# ShopFeed – Pure CSS Version

A responsive 5-page social e-commerce website built with **plain HTML + CSS + JavaScript** (no Tailwind or frameworks).

## Pages

1. **Home** (`index.html`) – Social product feed
2. **Explore** (`explore.html`) – Product grid with search & filters
3. **Product Detail** (`product.html`) – Full product page
4. **Cart & Checkout** (`cart.html`) – Cart + checkout form
5. **Sell** (`sell.html`) – Seller listing form

## Features

- Fully responsive (mobile-first)
- Shopping cart with localStorage
- Search & category filtering
- Social-style feed (likes, seller posts)
- Clean modern design with pure CSS
- Sample products + images

## How to Run

Open `index.html` in any browser, or use a local server.

## Tech

- HTML5
- Pure CSS (styles.css)
- Vanilla JavaScript
- Font Awesome (CDN)
